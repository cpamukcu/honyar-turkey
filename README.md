# Building Safer Homes, Together

Mid-term presentation for the Honyar Task (Global Strategy and Innovation, ZJU): a market entry plan for Honyar in Turkey.

- **Slides:** `index.html` — arrow keys or click to move, `N` notes, `F` full screen, `P` phone remote.
- **Phone remote:** `remote.html` — scan the QR code from the slides (press `P`) to move the slides and read the speaker notes on your phone.

The phone and the slides talk through public MQTT brokers (EMQX and HiveMQ), so both need an internet connection.
